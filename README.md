# C# Salary Calculator with Seniority Bonus

## 📌 Overview
A simple C# console application that calculates an employee's total salary based on hours worked, hourly rate, and years of service. It includes conditional logic to apply a fixed seniority bonus for long-term employees.

## 🚀 Features
- Prompts the user to input:
  - Number of hours worked
  - Hourly salary rate
  - Total years of service
- Calculates the base salary (`hours × rate`).
- Applies a **35 TND bonus** automatically if the employee has more than 10 years of seniority.
- Displays the final, formatted salary result in the console.
